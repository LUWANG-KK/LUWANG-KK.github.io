首先，全程免费，不需要任何付费（可能对电脑配置有一点要求，具体可以看 GitHub 里面有写，上面也是中文的）。

## 1. 下载安装包

第一步先是去 [GitHub](https://github.com/RVC-Boss/GPT-SoVITS?tab=readme-ov-file) 上去下载自己电脑对应系统的安装包。

我以自己的电脑为例子，我的是 Windows 系统，在这个 readme → installation → windows → 下载安装包。就是在这个点击就可以：

![在 GitHub readme 里找到 Windows 安装包的下载位置](/posts/gpt-sovits/01.webp)

## 2. 解压

下载下来是一个 zip 文件，用软件把 zip 解压，这里我一般用的软件是 7-Zip。

官网英文原版下载：<https://www.7-zip.org/download.html>

## 3. 打开

在目录里面打开这个文件：

![在解压出来的目录里找到要打开的文件](/posts/gpt-sovits/02.webp)

## 4. 弹出网页

这个就是刚才那个文件正常打开的样子：

![文件打开后的终端窗口](/posts/gpt-sovits/03.webp)

我的电脑是打开文件之后按了一下 enter，等了几秒才有反应。

## 5. 打开网页

这个就是网页打开的样子（文件夹忽略掉，是我练过的记录）：

![GPT-SoVITS 的 WebUI 界面](/posts/gpt-sovits/04.webp)

## 6. 把找到的音频放进去切割

在左边输入你音频的文件的路径，一般就是右键文件会出现文件路径，复制粘贴进去就可以了。

![语音切分界面，左边填输入路径，右边填输出文件夹](/posts/gpt-sovits/05.webp)

我这里是随便在网上找的 MP3 格式的音频，右边是输出文件夹，自己设置一个。剩下的所有参数我都没有动。

然后点击橙色的那个「开放式语音切片」就开始了。完成之后能看到说切割结束：

![提示切割结束](/posts/gpt-sovits/06.webp)

## 7. 语音识别

把刚才切割好的音频文件夹放到左边这个框里，右边自己设置一个输出文件夹，点击橙色方框「开放式语音识别」。其他的参数我也没有动。

完成之后能看到说任务结束：

![语音识别完成的提示](/posts/gpt-sovits/07.webp)

## 8. 训练模型

在这个最上面选择「1-GPT-SOVITS-TTS」这个方框，给你自己模型取个名字。剩下的不动。

在左边这个文本标签文件里面放进去刚才在「语音识别」这一步里面输出的文件，文件后缀为 `.list`。在右边这个音频数据文件里面放入在「切割」这一步里面输出的文件。

![训练模型界面，填入 list 文件和音频数据目录](/posts/gpt-sovits/08.webp)

一路拉到最下面，点击这个橙色方框「打开训练集一键格式化」。完成之后右边会写结束：

![一键格式化完成](/posts/gpt-sovits/09.webp)

## 9. 微调

在这个里面选择「1B-微调」。参数我都没动，点击橙色方框「开放式 sovits 训练」，等待右边出现训练完成。

这一步我等了一会儿，大概十多分钟，可以在终端里面查看进度。

![sovits 训练界面](/posts/gpt-sovits/10.webp)

往下拉，同样的步骤，点击橙色方框「开放式 GPT 训练」，等待右边出现训练完成：

![GPT 训练界面](/posts/gpt-sovits/11.webp)

## 10. 合成语音

切换到下一个「1C-推理」：

![切换到 1C-推理](/posts/gpt-sovits/12.webp)

点击方框「GPT 重量列表」和「sovits 重量列表」：

![刷新并展开重量列表](/posts/gpt-sovits/13.webp)

随便在里面选择一个你自己训练出来的模型：

![在列表里选择自己训练出的模型](/posts/gpt-sovits/14.webp)

选好模型之后，点击「开启 TTS 推理 webUI」，然后就会弹出一个新页面，就可以开始你想让他说什么就能说什么了。

![点击开启 TTS 推理 webUI](/posts/gpt-sovits/15.webp)

## 11. 输入你想要听的文本

在刚才弹出来的新页面里面选择你刚才选择的 xx 重量表：

![在推理页面选择模型](/posts/gpt-sovits/16.webp)

在这里上传一段 3–10 秒的音频，和输入一下这段音频的文本（没有也可以不写）：

![上传参考音频并填写对应文本](/posts/gpt-sovits/17.webp)

在下面填写你想要他说的话，我写的「祝你生日快乐」，点「开始推理」就可以了，右下角就有音频出来可以听。右下角还有一些参数可以自己摸索一下调整。

![填写要合成的文本并开始推理](/posts/gpt-sovits/18.webp)

然后你就可以让你想听到的声音，想说什么就说什么啦。也可以试试 AI cover。
