我主要用到的软件是Zotero，作为我主要的论文分类主库和论文标注。因为Zotero可以一边读一边做note，当然也可以选择下载Zotero 的chrome 插件.
下载插件的好处就是，如果你在网页上浏览论文的话，你可以点击一下Zotero的插件标志，他就可以自动的下载并且储存到app里面，非常方便。

当你上传你电脑里的所有文献的时候，它可以自动识别论文的标题作者等等一切信息，并且在右侧可以以缩略图的形式让你预览，无需一个一个打开论文。
当你在阅读论文的时候，你可以一边阅读一边做下划线，或者高亮，或者批注。右侧可以展现你这篇文章做的所有批注。

如何安装软件	
1）主程序
地址在这里：zotero.org/download，下载对应 Windows / macOS / Linux 的版本。
2） Zotero Connector（浏览器插件）
下载页面会同时提供 Connector，支持 Chrome、Firefox、Safari、Edge，装好后浏览器工具栏会出现一个小图标。看到期刊论文页面时，图标变成一张纸的样子，看到书籍时，变成一本书，看到搜索结果列表时，变成文件夹（可以批量勾选导入。
3）其他文字处理器插件
安装 Zotero 时会自动为 Word / LibreOffice 装插件，Word 顶部会多一个 Zotero 选项卡。
⚠️ 如果 Word 里没看到 Zotero 选项卡：先完全退出并重启 Word（视频里也提到这一点）；仍然没有的话，去 Zotero 的 设置 → 引用（Cite）→ 文字处理软件，点击"重新安装加载项"。 Google Docs 不需要装插件，在 Docs 里会直接出现 Zotero 菜单。

二、如何抓取文献
在浏览器打开一篇论文的页面（期刊网站、Google Scholar、PubMed、arXiv、知网等均可），点击 Connector 图标 → 选择存入哪个库/文件夹。Zotero 自动提取：作者、标题、期刊、年份、卷期页码、DOI、摘要。如果 PDF 可以下载，会一并存进来。Zotero的亮点是当你没有论文的订阅权限时，它会尝试寻找开放获取版本（作者上传的预印本 / 接收稿）。

其他四种入库方式
方式一：拖拽 PDF 进 Zotero 窗口。
如果手上已有一堆 PDF。Zotero 会自动识别 DOI 并补全题录
方式二：通过标识符添加（工具栏的魔棒图标 🪄）	
如果已知 DOI / ISBN / PMID / arXiv ID，粘进去即可
方式三：导入 .ris / .bib / .enw 文件	从数据库批量导出，或从 EndNote / Mendeley 迁移
方式四：手动新建条目	灰色文献、内部报告、网页等抓不到的内容
补全题录的小技巧：现在把 PDF 拖进 Zotero 时会自动尝试识别元数据。如果没识别成功，右键该 PDF → "创建父条目"（Create Parent Item），粘贴 DOI / ISBN，或选择手动填写。

三、如何组织你的个人论文数据库：从"一堆文献"到"一个数据库"
分类文件夹（Collections）
左侧栏右键 → 新建分类。建议按项目而不是按主题建：
我的文库
├── 📁 进行中项目
│   ├── 数字媒体与青少年心理健康（论文A）
│   └── XX 综述
├── 📁 已完成
│   └── 2025 硕士论文
└── 📁 待读清单
重要机制：Zotero 的分类是"标签式"的，同一篇文献可以同时属于多个分类，不会产生副本。
直接拖拽（不按任何键）= 添加到新分类，原分类仍保留
按住 Shift（Windows/Linux）/ Cmd（Mac） 拖拽 = 移动（从原分类移除）
想知道一篇文献属于哪些分类？选中它然后按住 Ctrl（Windows）/ Option（Mac），相关分类会高亮
标签（Tags）
分类管"文献属于哪个项目"，标签管"文献是什么"。常用的标签体系：
方法类：RCT、meta分析、队列研究、质性研究
状态类：已精读、待读、核心文献、存疑
主题类：社交媒体、抑郁、青少年
标签可以设颜色（最多 9 个上色标签），上色后会在条目列表左侧显示小方块，还能用数字键 1–9 快速打标签。建议把"核心文献""待读"这类高频状态标签设成彩色。
保存的检索（Saved Searches）
这是 Zotero 最被低估的功能。左侧栏右键 → 新建保存的检索，设条件后会生成一个自动更新的智能文件夹。

实用例子：
添加日期 在最近 30 天内 → 本月新增文献
标签 不包含 已读 + 分类 是 项目A → 项目 A 里的待读清单
附件文件类型 不是 PDF → 找出所有缺全文的条目，方便补齐
重复条目与无分类条目
左侧栏底部有两个内置视图：
重复条目（Duplicate Items）：选中后点右上角 "Merge" 合并，定期清理
未分类条目（Unfiled Items）：抓完文献忘了归类的会掉在这里，定期清空
文件命名（Zotero 8+ 强化）
设置 → 常规 → 文件重命名，可以让 PDF 自动按 作者_年份_标题 命名，并且在题录信息修改后持续同步更新文件名。这样即使哪天不用 Zotero 了，你的 PDF 文件夹依然是整齐可读的。

四、如何使用Zotero来阅读与做笔记
双击条目 → 在 Zotero 内置阅读器里打开（支持 PDF、EPUB、网页快照）。
高亮 / 下划线 / 区域截图 / 文字标注：工具栏切换
每个标注可以单独加注释和标签
顶部标签页（tabs）机制，可以同时开多篇论文
笔记的两个层级
条目笔记：附在某篇文献下，写这篇的读书笔记
独立笔记：不隶属任何文献，用来写综述提纲、想法汇总
在笔记里输入 @ 可以直接搜索并插入引用；也可以把 PDF 里的高亮一键拖进笔记，Zotero 会自动带上页码和引用。
💡 建库建议：养成给每篇核心文献写 3 句话笔记的习惯——研究问题、方法、结论。

五、写作引用
1.如何插入引用
Word → Zotero 选项卡 → Add/Edit Citation
首次使用会弹出样式选择框，选 APA 7th edition（或 MLA、Chicago、Nature、Vancouver 等）
需要其他期刊的样式：点 "Manage Styles" → "Get additional styles"，Zotero 样式库有 10000+ 种
弹出搜索条（红色小框），可按标题或作者名搜索，也会直接列出你当前打开的 PDF
选中 → 回车 → 引用插入完成
加页码等细节：在搜索条里选中文献后点一下它，可以填页码、前缀（如 "e.g., "）、后缀。
生成参考文献表：
光标移到文末 → Add/Edit Bibliography → 自动生成完整参考文献列表。
保持同步：
后续增删引用后，点 Refresh，正文引用和文末列表会一起更新。换期刊投稿时，点 Document Preferences 换个样式，全文引用格式秒变。
⚠️ 投稿前务必做的一步：另存一个副本，点 Unlink Citations 去掉 Zotero 域代码，再提交给期刊。原文件保留链接以便后续修改。

六、同步与备份
注册账号并开启同步
去 zotero.org 注册免费账号
Zotero 设置 → 同步 中登录
点右上角的同步按钮 🔄 手动强制同步
同步分两部分：
题录数据同步：无限量、永久免费
文件（PDF）同步：免费 300 MB
存储空间怎么办
方案	说明
免费 300 MB	大约存 100–200 篇 PDF
付费	2 GB / $20 年，6 GB / $60 年，无限 / $120 年
用 WebDAV（省钱方案）	在设置里把文件同步改成 WebDAV，接坚果云等服务，题录仍走 Zotero 官方服务器
只同步题录	关掉文件同步，PDF 存本地，配合网盘同步 Zotero 数据文件夹
⚠️ WebDAV 只对个人文库有效，群组库不支持 WebDAV。群组库的文件必须用 Zotero 官方存储，且额度算在群主账号头上，不占其他成员配额——所以如果你要建大型群组库，让配额最多的人当群主。

备份
Zotero 的全部数据在一个文件夹里（设置 → 高级 → 文件和文件夹 可查看路径）。定期把整个 Zotero 文件夹复制到移动硬盘或网盘，这是最可靠的备份。注意：备份前先完全退出 Zotero。

七、群组库：和别人共建文献库
创建群组
登录 zotero.org → 头像 → Groups 标签页 → Create a New Group
起名（比如课程名或项目名），选择 Private Membership（私有）或公开
创建后回到 Zotero 客户端，点右上角同步按钮，左侧栏就会出现这个群组库
使用
把文献从"我的文库"拖进群组库，成员即可看到题录、PDF 和笔记
邀请成员：群组页面 → Members Settings → Send More Invitations，输入对方的 Zotero 用户名或邮箱
成员点同步按钮即可看到更新
Zotero 9 起，群组库多了 "Added By" / "Modified By" 列，能看到是谁加的、谁改的

八、推荐插件（进阶）
插件	
Better BibTeX	LaTeX 用户必装，生成稳定的 citation key，自动导出 .bib
Zotero Style / Ethereal Style	在条目列表显示期刊影响因子、分区、阅读进度
Jasminum（茉莉花）	中文用户：修复知网抓取的题录，拆分中文作者姓名
ZotFile（部分功能已被 Zotero 8+ 内置取代）	PDF 重命名与外部文件夹管理
Zotero Reading List	给文献标记"待读/在读/已读"状态
安装方式：下载 .xpi 文件 → Zotero 工具 → 插件 → 齿轮图标 → Install Add-on From File。

常见问题
Q：Connector 抓不到题录怎么办？ A：换个入口试试（比如从 Google Scholar 或出版社官网），或者复制 DOI 用魔棒图标添加。中文数据库建议装 Jasminum 插件。
Q：抓到了题录但没 PDF？ A：手动下载 PDF 后直接拖到该条目上即可挂载；或右键条目 → "查找可用的 PDF"。
Q：从 EndNote / Mendeley 迁移？ A：在原软件里导出 RIS 格式，Zotero 文件 → 导入。PDF 附件通常也能一并迁移。
Q：Zotero 收费吗？ A：软件本身完全免费开源，只有云端文件存储超过 300 MB 才需付费，且可用 WebDAV 免费替代。
